### 🧠 Bring Your AI Characters to Life With Real Living Memory
Most AI companions and NPCs suffer from **flat amnesia**: traditional RAG systems treat past conversations as rows in a spreadsheet, lacking context, depth, or emotional significance.

The **3D Weaire–Phelan Living Memory Core** changes that. Built on **3D continuous geometric coordinates** and **associative spiderweb graph traversal**, it organizes thoughts into a living 3D spatial lattice where ideas connect, evolve, and resonate over time.

---

### 🌟 Key Highlights & Superpowers:

* 🫧 **3D Continuous Coordinate Lattice**: Memories are assigned physical $(X, Y, Z)$ coordinates mapping **Domain Map**, **Emotional Resonance**, and **Temporal Depth**.
* 🕸️ **2-Stage Spreading Activation Retrieval**: Blends local ChromaDB embeddings with multi-hop graph energy diffusion to retrieve associative context that flat vector searches miss.
* 👁️ **Spaced-Repetition Retrieval Reinforcement**: Frequently recalled memories gain permanence; unused trivial notes decay gracefully.
* 🎭 **Affective Character Agency**: Includes Valence-Arousal-Dominance (VAD) emotional tracking, a conversational salience filter (rejects filler like `"ok cool"`), and autonomous memory reflection consolidation.
* 🚀 **100% Offline, Local & Free Forever**: Powered locally by `all-MiniLM-L6-v2` embeddings. Zero cloud subscriptions or API fees.
* 🔒 **Zero-Knowledge Fernet Encryption**: Built-in optional AES-128-CBC + HMAC encryption to keep user conversations completely private on disk.
* 🧹 **Intelligent Multi-Factor Pruning**: Automatically purges decayed memories using weight, strand density, access count, and recency.
* 🖥️ **Themeable Desktop Viewer**: Includes a stunning CustomTkinter UI for visual cluster browsing, live metric monitoring, access badges, and strand inspection.
